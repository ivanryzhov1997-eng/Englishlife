# English RPG v2 — fixed
Готово для GitHub Pages.
1. Создай репозиторий.
2. Загрузи `index.html`, `style.css`, `app.js`.
3. Settings → Pages → Deploy from branch → main → root.
4. Открой ссылку Pages.
В приложении ⚙️ → endpoint / model / API key.
Ключ хранится в localStorage браузера. Не публикуй его в GitHub; для публичного приложения нужен backend/serverless proxy.
В этой версии исправлены: закрытие настроек после сохранения, кнопки Отмена/×, удаление ключа, сохранение настроек и ежедневный reset главного квеста.
